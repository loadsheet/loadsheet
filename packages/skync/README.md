# skync

skync will put the same agent skills in Claude Code, Codex, Cursor and Gemini on every machine you use. A timer pulls new versions of those skills, so nobody copies them by hand.

It's not released yet. The npm package only holds the name for now, and running it prints this status. Follow along at [onmax/skync](https://github.com/onmax/skync).
